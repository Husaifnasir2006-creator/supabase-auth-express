# Express Supabase Auth API

This project is a simple authentication API built using **Node.js, Express.js, and Supabase Auth**.

## Features

* User Sign Up
* User Login
* Supabase Authentication
* Express.js API endpoints
* Postman API testing

## Technologies Used

* Node.js
* Express.js
* Supabase
* JavaScript
* Postman

## API Endpoints

### Sign Up

```text
POST /signup
```

Creates a new user account using Supabase Authentication.

### Login

```text
POST /login
```

Logs in an existing user using Supabase Authentication.

## Installation

Clone the repository and install the required packages:

```bash
npm install
```

Create a `.env` file and add your Supabase credentials.

Then start the server:

```bash
node server.js
```

The API will run on:

```text
http://localhost:3000
```

## Testing

The APIs were tested using **Postman**.
